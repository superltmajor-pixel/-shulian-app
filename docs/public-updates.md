# 公开测试版下载与更新

计划使用的官方发布页为 <https://github.com/superltmajor-pixel/-shulian-app/releases>。
当前正在准备首个公开测试版，页面及下载包尚未发布。应用中的下载按钮在发布准备完成后才会启用。

## 如何获取新版

无需配置 Python、Git 或本机源码。发布后，在设置的“更新与卸载”中选择“打开公开下载页”，阅读版本说明并下载 Windows 完整 ZIP。尚未配置 AI 服务时，连接界面也提供相同入口。

当前入口通过系统浏览器打开发布页，不自动查询线上版本、不下载或安装更新，也不会把本机版本显示为“线上最新”。已有完整本机开发环境的用户仍可使用源码构建更新。

## 保留个人数据

1. 完全退出数恋，包括托盘中的程序。
2. 备份原程序整个目录及 `%LOCALAPPDATA%\Shulian`。后者包含默认角色库、聊天数据库和凭据等；原程序目录的 `webview-data` 保存界面状态及部分历史信息。若配置了自定义数据位置，也需要单独备份。
3. 下载完整 ZIP 并解压到一个新目录，保留程序的完整目录结构；不要只复制 `Shulian.exe`。
4. 将旧程序目录中的 `webview-data`、`media`、`local-data` 和 `.env`（如有）复制到新程序目录下的同名位置。不要用新包覆盖或清空 `%LOCALAPPDATA%\Shulian`，不要把旧的 EXE 和 `_internal` 混入新版本。自定义数据路径应继续指向原位置。
5. 在同一台电脑、同一 Windows 用户下运行新版，确认原角色、聊天、设置及自建角色编辑保存正常。验证通过前保留旧程序和备份，不要先卸载或选择“清除数据”。

角色 ZIP 导出目前不等于所有高级角色扩展与聊天状态的完整备份。完整备份可能包含私密聊天与凭据，请仅保存在自己的安全位置，不要上传到 GitHub 或问题反馈中。

若新版无法使用，先退出新版，保留其数据副本，再按发布说明恢复旧程序及升级前数据备份。涉及数据格式迁移时，应遵守该版本的回退说明，不要直接让旧程序写入不兼容的新数据。

## 发布维护说明

- `release.json` 的 `publicReleaseUrl` 配置发布页；仅接受 HTTPS GitHub 仓库的 `/releases` 页面。
- `publicReleaseReady` 当前为 `false`，应用显示“下载页尚未开放”。只有在新仓库与实际发布流程准备好后，才将它置为 `true` 并重新构建待发布包。
- 发布前重新确认版本、Build ID、前端缓存标识、维护清单与所发布源码提交一致。不要只修改已生成的 EXE 或 ZIP。
- GitHub 仓库创建、提交、标签、包上传及公开均是单独发布操作；本配置不执行这些操作。
